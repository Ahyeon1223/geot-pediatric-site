## 1. 정리 단계 — 심평원 의원

| 단계 | 건수 |

| − 기관 ID(`ykiho`) 빈값 | 0 |
| − 기관 ID 중복 | 0 |
| − 기관명 빈값 | 0 |
| − 기관명에 '소아' 없음 | 12,074 |

검산: 14,191 − 0 − 0 − 0 − 12,074 − 1 = 2,116 → 맞음

제외한 1곳: 경기 시흥시 '재)아주산업의학연구소아주의원'. 이름의 '연구소 + 아주'가 붙으면서 '소아'가 생긴 것이라 소아청소년과 의원이 아니므로 팀 확인 후 제외했다(11/25, `clean.py`의 `NAME_FALSE_MATCHES`). 이 1곳 때문에 바뀐 값은 시흥시 의원 수 34 → 33뿐이다.

0건 확인 방법: 빈 ID는 `ykiho`를 공백 제거 후 빈 문자열인지, 중복은 `ykiho` 값이 두 번 이상 나오는지 전체 행에서 셌다. `collect.py`도 저장 전에 같은 검사를 하고, 시도별 받은 건수가 API `totalCount`와 같은지 확인한다.

## 3. 결합 단계

| 단계 | 건수 |
|---|---:|
| 심평원 시군구 조합 (시도코드+시군구코드) | 254 |
| = 매칭 성공 + 매칭 실패 | 254 + 0 |
| 정리 후 의원 | 2,116 |
| = 매칭 성공 + 매칭 실패 | 2,116 + 0 |
| KOSIS 시군구 | 256 |
| = 심평원에 있음 + KOSIS에만 있음 | 254 + 2 |

검산: 지역별 의원 수 합계 2,116 = 매칭 성공 의원 2,116 → 맞음

매칭 실패 목록

- KOSIS 경상북도 영양군 (47760): 심평원 수집본에 이 지역 의원이 한 곳도 없음 (소아청소년과 진료과목 의원 0곳)
- KOSIS 경상북도 울릉군 (47940): 심평원 수집본에 이 지역 의원이 한 곳도 없음 (소아청소년과 진료과목 의원 0곳)

0건 확인 방법: 매칭은 시도 이름과 시군구 이름을 같이 비교한다(중구·동구처럼 겹치는 이름 때문). 같은 이름이 두 지역에 걸리면 매칭하지 않고 실패로 남기며, 의원 매칭 실패가 1건이라도 있으면 `clean.py`가 멈춘다.
