- 실행일: 2026-11-15
- 실행자: 김아현 (화면 담당) — 데이터 담당에게 넘기는 기록
- 실행 코드: `src/test_hira_api.py`
- 실행 방법: `.env`에 본인 키(`HIRA_API_KEY=...`)를 넣고 `python src/test_hira_api.py`
- 요청 주소: `https://apis.data.go.kr/B551182/hospInfoServicev2/getHospBasisList`

## 한 줄 요약

API는 정상 작동한다. 단, **진료과목 필터만으로는 소아청소년과 의원을 셀 수 없고**, **시군구 코드는 심평원 자체 코드라 행정코드 매핑표가 필요하다.**

## 1. 확인한 코드값 (모두 맞음)

| 파라미터 | 값 | 의미 |
|---|---|---|
| `sidoCd` | `110000` | 서울 |
| `clCd` | `31` | 의원 (종류) |
| `dgsbjtCd` | `11` | 진료과목: 소아청소년과 |

## 2. 건수 (서울)

| 단계 | 조건 | 건수 |
|---|---|---|
| ① | 서울 의원 전체 | 10,749 |
| ② | ① + 진료과목 소아청소년과 (`dgsbjtCd=11`) | 3,049 |
| ③ | ② 중 이름(`yadmNm`)에 '소아' 포함 | **443** |

**②를 그대로 쓰면 안 되는 이유:** 진료과목 필터는 소아청소년과를 *진료과목 중 하나로라도* 등록한 의원을 모두 돌려준다. 실제 결과에 `연세건강증진내과의원`, `열린의원` 같은 곳이 섞여 있다.

**잠정 기준:** 이름에 '소아'가 들어간 의원 = 소아청소년과 의원 (③, 443곳). 예시 이름은 다음과 같다.
`가야소아청소년과의원`, `강경훈소아과의원`, `강남연세소아과의원`, `강남조앤조내과소아과의원`, `강석경소아과의원`

## 3. 시군구 코드 형식

- `sgguCd`는 **6자리 심평원 자체 코드**다. 예: `110003` 강서구, `110023` 광진구, `110017` 중구, `110008` 동작구, `110018` 송파구, `110002` 강동구
- 행정표준코드(5자리, 예: 강서구 `11500`)와 형식이 달라 KOSIS 인구와 바로 결합할 수 없다.
- 대신 `sidoCdNm` + `sgguCdNm`(이름)이 함께 오므로 **이름 기준 매핑표**를 만들 수 있다.

## 4. 응답 필드

`addr`, `clCd`, `clCdNm`, `drTotCnt`, `estbDd`, `emdongNm`, `postNo`, `sgguCd`, `sgguCdNm`, `sidoCd`, `sidoCdNm`, `telno`, `XPos`, `YPos`, `yadmNm`, `ykiho`, 그리고 의사 수 세부 필드(`mdept*`, `dety*`, `cmdc*`), `pnursCnt`

서비스에 쓸 만한 필드:

| 필드 | 뜻 | 쓰임 |
|---|---|---|
| `yadmNm` | 기관명 | 소아청소년과 판별 (이름에 '소아') |
| `sidoCdNm`, `sgguCdNm` | 시도·시군구 이름 | 인구 데이터와 매핑 |
| `XPos`, `YPos` | 경도·위도 | 화면 지도 표시 |
| `estbDd` | 개설일 (YYYYMMDD) | 최근 개원 추세 |
| `drTotCnt` | 의사 총수 | 의원 규모 |
| `ykiho` | 기관 고유 암호코드 | 중복 제거용 키 |

## 5. 아직 확인 못 한 것 / 주의할 점

- **이름 기준의 한계:** '소아'가 이름에 없는 소아 진료 의원(예: '○○아이들의원', '○○어린이의원', '키즈')은 빠질 수 있다. 전국 수집 때 이런 이름이 얼마나 있는지 한 번 확인하고 기준을 정할 것.
- 반대로 `강남조앤조내과소아과의원`처럼 내과와 함께 건 곳도 포함된다. 일단 포함으로 둔다.
- 이 API는 *현재 운영 중인* 기관 목록이다. 폐업 이력은 나오지 않는다.
- 한 번에 500건씩 받아도 문제없었다 (`numOfRows=500`).

## 6. 데이터 담당이 이어서 할 일

1. **전국 수집** (`src/collect.py`): `clCd=31`, `dgsbjtCd=11`로 시도별로 반복 수집해서 `data/raw/`에 저장한다. 이름에 '소아'가 들어간 것만 남기는 건 `clean.py`에서 한다.
2. **매핑표**: 심평원 `sgguCd`/이름을 행정표준코드 5자리로 연결한다. `중구`, `동구`, `서구`, `남구`, `북구`처럼 **이름이 겹치는 구가 여러 시도에 있으니** 반드시 시도 이름과 같이 맞출 것. 일반구가 있는 시(예: 수원시 ○○구)는 KOSIS 단위와 맞는지 확인한다.
3. **KOSIS 인구**: 시군구별 0~14세 주민등록인구를 받아 매핑표로 결합한다.
4. **지표 계산**: 시군구별 `소아청소년과 의원 수 ÷ 0~14세 인구 × 10,000`
5. **건수 검증표** (`reports/count_check.md`): 수집 건수 → 이름 필터 후 → 매핑 성공/실패 건수를 단계별로 적는다.
