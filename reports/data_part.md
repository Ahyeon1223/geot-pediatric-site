# 팀 프로젝트 데이터 파트 전달 안내

## 1. 심평원 의원 데이터 수집

```bash
python src/collect.py
```

- 심평원 병원정보서비스 API에서 의원(`clCd=31`) 중 소아청소년과를 진료과목으로 신고한 기관(`dgsbjtCd=11`)을 수집함.
- 최종 수집 결과는 `data/raw/hira_pediatric_candidates.csv`에 저장됨.
- 이번 수집본은 **16개 시도 코드, 14,191건**이며, 기관 ID(`ykiho`) 빈값·중복은 **0건**임.

## 2. KOSIS 인구 데이터 준비

- KOSIS에서 **`행정구역(시군구)별/1세별 주민등록인구`**라고 검색. (통계표 코드는 DT_1B04006) 
다운로드 페이지에서 **2026년 월자료 101_DT_1B04006_M_2026** (101_DT_1B04006_M_2026.csv)를 내려받아 `data/raw/`에 넣으면 데이터 준비 끝. (그중 10월 자료만 사용)

## 3. 전처리 및 결과 파일

```bash
python src/clean.py
```

심평원 수집본 중 기관명에 **‘소아’**가 포함된 의원을 남김. 시도·시군구 명칭을 기준으로 KOSIS 지역코드를 부여한 뒤, 지역별 의원 수를 집계해 인구 데이터와 결합함. 기관명에 ‘소아’가 없으면 소아청소년과를 진료과목으로 신고한 의원도 이번 집계에서 제외될 수 있음.

| 생성 파일 | 내용 및 용도 |
|---|---|
| `data/processed/regions.csv` | **지역별 요약표, 256개 지역.** 기존 `api.py`가 읽는 `code`, `sido`, `sigungu`, `child_pop`, `clinic_count`와 최근 3년 개설 건수인 `recent_3yr_openings`까지 총 6개 열임. |
| `data/processed/clinics.csv` | **의원별 상세 목록, 2,116곳.** `region_code`, `clinic_name`, `address`, `longitude`, `latitude`, `opened_date`를 제공함. 현재 `api.py`는 지역 요약을 반환하며, 요건정의서에 있는 "지역 선택 시 의원 목록과 지도 위치를 보여주는 상세 기능"에 이 파일을 사용할 수 있음. |
| `reports/region_mapping.csv` | **시군구 매핑표, 총 256개 지역.** 심평원 수집본과 KOSIS 인구표의 지역을 대조한 결과임. **256개 = 매칭 성공 254개 + 매칭 실패 2개.** 경상북도 영양군·울릉군은 ‘KOSIS에만 있음’으로 표시되며, 심평원 수집본에만 있는 지역은 0개임. |

regions.csv의 `recent_3yr_openings`는 최종 집계 대상 의원 2,116곳 중 **2023년 11월 1일~2026년 10월 31일**에 개설한 곳을 지역별로 센 값임. 전국 합계는 **137곳**임.

## 4. 서버 연동

- 현재 지역 조회 API는 `data/processed/regions.csv`를 읽음. 생성된 CSV가 있으면 심평원 API 키 없이 서버를 실행할 수 있음.
- 의원 목록을 연결할 때는 `regions.csv`의 **`code`**와 `clinics.csv`의 **`region_code`**를 문자열로 읽어 연결하면 됨.
- 두 결과 CSV를 받으면 수집·전처리를 다시 실행하지 않고 바로 연동 작업을 시작할 수 있음.

## 5. 시도 코드 참고

이번 심평원 수집본은 **16개 시도 코드** 기준임. 광주와 전남은 통합(2026.7) 이후의 **전남광주** 기준으로 처리하며, 이전 광주 코드 `240000`은 별도 수집 대상으로 나오지 않음.

### 주요 열 및 집계 기준

- `child_pop`은 2026년 10월 기준 0~14세 주민등록인구임.
- `clinic_count`는 소아청소년과를 진료과목으로 신고한 의원 중 기관명에 ‘소아’가 포함된 의원의 수임. `recent_3yr_openings`는 그중 2023년 11월 1일부터 2026년 10월 31일까지 개설한 의원의 수임.
- `regions.csv`의 `code`와 `clinics.csv`의 `region_code`를 문자열로 읽어 연결함.
