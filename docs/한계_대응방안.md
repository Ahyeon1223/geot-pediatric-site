# 한계 대응방안 구현 (계획서 '범위와 한계')

계획서에 적은 한계 4가지의 대응방안을 코드로 옮긴 내용입니다.
**기본 지표(소아 1만 명당 의원 수)와 기본 순위는 바꾸지 않았습니다.** 보조 지표는 열을 덧붙이기만 해서
건수 검증표의 숫자(256개 시군구, 의원 2,117곳, 종로구 4.51)는 그대로입니다.

| 한계 | 대응방안 (계획서) | 구현 | 파일 |
|---|---|---|---|
| ① 기관명에 '소아'가 없는 소아 진료 의원 누락 | '어린이·아동' 등 키워드 추가, 누락 의심 의원은 검증표에 기록 | 어린이·아동·키즈 키워드로 잡히는 의원을 `clinic_count_broad`(참고 열)와 `reports/name_keyword_check.csv`(누락 의심 목록)에 남김. 기본 `clinic_count`는 '소아'만 | `src/clean.py` |
| ② 시군구 경계를 넘는 진료 수요 | SGIS 경계로 인접 시군구를 찾아 인접 합산 지표를 보조 지표로 | 경계 파일에서 맞닿은 시군구 표를 만들고(`data/reference/sigungu_adjacency.csv`), 자기 지역 + 맞닿은 지역의 의원 수 ÷ 소아 인구로 `clinics_per_10k_with_neighbors` 계산 | `src/build_adjacency.py`, `src/indicators.py` |
| ③ 수집 시점 스냅샷, 폐업 시점 모름 | 화면에 데이터 기준일 표시, collect.py 재실행으로 갱신, 연도별 개설 수로 추이 보완 | `regions.csv`에 `population_month`(인구 기준월), `hira_collected`(심평원 수집일) 열 추가, 서버 `GET /meta`로 내보냄. 상세 `GET /regions/{code}`에 최근 10년 `openings_by_year` | `src/clean.py`, `src/api.py` |
| ④ 의원 1곳 = 1로 집계 | API의 의사 수로 '소아 1만 명당 의사 수'를 보조 지표로 검토, 야간 진료는 범위 밖 | 심평원 `drTotCnt`를 `clinics.csv`·`regions.csv`의 `doctor_count`로 남기고 `doctors_per_10k` 계산. 야간 진료는 범위 밖으로 `/meta` 설명에 적음 | `src/clean.py`, `src/indicators.py` |

## 실제 데이터로 확인한 숫자 (드라이브의 전국 심평원 수집본 14,191건)

| ① 추가 키워드로 더 잡히는 곳 | 9곳 (아동 4, 키즈 5, 어린이 0) → 참고 열 합계 2,126곳 |
| ④ 2,117곳의 의사 수 합계 | 2,708명 (의사 수 0으로 신고된 의원 6곳) |
| ③ 개설 연도별 (2,117곳 중 지금 영업 중) | 2017년 84 · 2018년 78 · 2019년 86 · 2020년 81 · 2021년 68 · 2022년 78 · 2023년 61 · 2024년 61 · 2025년 44 · 2026년(10월까지) 24 |
| ② 인접표 | 시군구 252개, 맞닿은 쌍 645개 |

서울만 넣고 `clean.py`를 돌린 결과, 기존 6개 열은 PR #1의 서울 샘플(`data/sample/regions.csv`)과 한 글자도 다르지 않았습니다.
종로구 보조 지표 손계산:

- 의사 수: 6 ÷ 8,870 × 10,000 = **6.76**
- 인접 합산: 종로구·중구·동대문구·성북구·은평구·서대문구 의원 68곳 ÷ 소아 140,903명 × 10,000 = **4.83**
  (고양시 덕양구도 맞닿지만 서울 샘플에는 없어서 빠짐. 전국 데이터에서는 들어감)

## 근사로 처리한 부분 (발표 때 한계로 말할 것)

- **경계 파일**: SGIS 키 없이 받을 수 있는 공개본(통계청 SGIS 경계 기반 행정동 경계, github.com/vuski/admdongkor ver20250401)을 썼습니다. SGIS에서 직접 받은 경계로 바꾸려면 `python src/build_adjacency.py 파일.geojson --code-field ... --sido-field ... --name-field ...`로 다시 만들면 됩니다.
- **2025년 4월 이후 바뀐 시군구**는 옛 지역 경계로 대신했습니다(`src/indicators.py`의 `FORMER_AREAS`).
  - 화성시 만세구·효행구·병점구·동탄구 → 4개 구 모두 옛 화성시 전체의 이웃을 씀
  - 인천 제물포구 → 옛 중구+동구, 검단구 → 옛 서구, 영종구 → 섬이라 맞닿은 곳 없음
  - 전남광주는 코드가 바뀌어 이름으로 연결
  - 2026년 10월 시군구 256개를 같은 방식으로 맞춰 보면 256개 모두 연결됨(가상 목록으로 확인, 실제 KOSIS 목록으로 한 번 더 확인 필요: `GET /summary`의 `no_boundary_names`가 빈 목록이면 됨)
- **섬**(울릉군, 옹진군, 완도군, 진도군, 거제시, 남해군, 영종구)은 다리·배편을 반영하지 않아 맞닿은 곳이 없고, 인접 지표 = 기본 지표입니다.
- **개설 연도별 수**는 지금 영업 중인 의원만 셉니다. 폐업한 의원은 심평원 원본에 없어서 과거 연도일수록 실제 개원 수보다 적게 나옵니다.
- **의사 수(drTotCnt)**는 그 의원의 전체 의사 수라 소아청소년과 전문의만의 수는 아닙니다.
